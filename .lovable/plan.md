# ALUVERA ALUMINIUM WORKS Website

## Goal
Build a polished, responsive one-page company website for ALUVERA ALUMINIUM WORKS, using the supplied content only and preserving the final clean logo exactly as uploaded.

## Required assets before completion
- One clean original Aluvera logo file, without the phone status bar or screenshot margins.
- Five labeled team photos: Mohmmed Al Arjaa, Fawzy Alqedra, Stephen Asante, Beddiaf Imen, and Yasmine Oukacha.

If these are not all available when implementation starts, temporary placeholders will be used only to assemble the layout, then replaced before final delivery.

## Page structure
1. **Header and introduction**
   - Prominent unmodified Aluvera logo.
   - “ALUVERA ALUMINIUM WORKS” and “ALUMINIUM & DECOR WORKS”.
   - “Our Services” and “Contact Us” buttons with smooth in-page scrolling.
   - Restrained navigation matching the requested sections.

2. **Our Services**
   - A responsive grid containing all 17 requested services.
   - Each card includes a relevant professional architectural image, title, and short description.
   - Clicking a card opens an accessible detail view containing its image, full description, and complete service/application list exactly as supplied.

3. **Our Solutions**
   - Residential, Commercial, Architectural, Custom, and Maintenance, using only the supplied descriptions.

4. **Why Aluvera**
   - Quality, Durability, Custom Solutions, Modern Design, Professional Installation, and Maintenance.

5. **Our Team**
   - Five professional profiles using the supplied names, roles, and uploaded real photographs.

6. **Contact Us**
   - Clickable Instagram, TikTok, Google Maps, WhatsApp, and email actions.
   - WhatsApp opens +971 56 900 9690 with the exact pre-filled inquiry message.

## Visual direction
- Architectural luxury with an off-white primary canvas, black typography and controls, and restrained beige accents.
- Minimal, editorial composition with crisp lines, disciplined spacing, and no unnecessary color.
- Strong mobile layout, readable service details, touch-friendly controls, and no overlapping content.
- Subtle entrance and interaction transitions only, with reduced-motion support.
- Professional project imagery across the services; no extra gallery, testimonials, pricing, blog, or unrequested copy.

## Technical details
- Implement the page at `/` with semantic sections and one H1.
- Store the final uploaded logo and team photos through the project asset system without modifying their pixels.
- Use reusable data-driven service cards and an accessible modal/detail panel with keyboard close, focus handling, and scroll-safe mobile behavior.
- Use semantic design tokens for all colors and styling.
- Add route-specific title, description, Open Graph metadata, and Twitter card metadata.
- Optimize image loading and verify every external action, section link, modal interaction, desktop layout, and mobile layout in the running preview.
